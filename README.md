# FTC Team 39068 "Spaghetti code"

Official robot control software repository for **FTC Team 39068 "Spaghetti code"**.

## Project Structure

- **`TeamCode`**: Contains our custom OpModes, autonomous routines, localizers (Pedro Pathing / Pinpoint / OTOS / Dead Wheels), and tuning utilities.
- **`FtcRobotController`**: FTC Robot Controller core framework.
- **`FtcDashboard`**: Dashboard integration for real-time telemetry and tuning.

## Development & Deployment

1. Open the project in **Android Studio Narwhal** or later.
2. Select the `:TeamCode` module and deploy to the Robot Controller Control Hub.
